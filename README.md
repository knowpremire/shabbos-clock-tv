# Shabbos Clock · TV

The Chromecast receiver for Shabbos Clock: the clock's display in TV mode. The phone app starts it
on a Chromecast and sends it the Shabbos times and settings. Built from the app's `receiver/` folder;
don't edit here.

The clock font (`clock-font.otf`, Nimbus Sans Narrow Bold from URW base35) is under the license in
`FONT-LICENSE.txt`. Weather data by Open-Meteo.com (CC BY 4.0). Shabbat times provided by
Chabad.org/ShabbatTimes.
